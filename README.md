# Исследование интернет-магазина "Подарочек"

Основная задача проекта изучить, проанализировать данные и предоставить рекомендации заказчику по дальнейшему ведению бизнеса.
Выделить наиболее активные категории клиентов и предложить стратегию по взаимодействию с ними. 
Оценить ключевые показатели бизнеса. На основе этих показателей сформулировать выводы о том, развивается бизнес или нет.

В файле **Исследование интернет-магазина.ipynb** представлена аналитическая записка.
Аналитическая записка включает в себя:
1. Предобработка данных
2. Исследовательский и статистический анализ
3. Расчет необходимых метрик
4. Графики
5. Основные выводы исследования
